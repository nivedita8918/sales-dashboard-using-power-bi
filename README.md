# Sales Dashboard Using Power BI

An interactive Power BI dashboard for tracking sales performance, product trends, and regional results.

## Dashboard goals

- Monitor revenue, profit, quantity sold, and growth over time.
- Compare results by product, category, region, and sales representative.
- Identify top-performing products and areas that need attention.

## Suggested report pages

1. **Executive Summary** — headline KPIs, monthly sales trend, and regional performance.
2. **Product Analysis** — category and product-level revenue, profit, and quantity.
3. **Regional Analysis** — map, regional comparisons, and drill-downs.
4. **Customer Insights** — customer segments, repeat purchases, and top customers.

## Project structure

```text
powerbi/       # Power BI .pbix report file
data/          # Source data files (CSV, Excel, etc.)
docs/          # Data dictionary, requirements, and notes
screenshots/   # Exported report visuals
```

## Getting started

1. Start with `data/superstore_sales_500.csv`.
2. Open Power BI Desktop and import the data.
3. Create relationships and calculated measures.
4. Build the report pages listed above.
5. Save the report as `powerbi/sales-dashboard.pbix`.
6. Add screenshots and update this README as the dashboard evolves.

## Core KPIs

- Total Sales
- Total Profit
- Profit Margin
- Quantity Sold
- Sales Growth (MoM / YoY)
- Average Order Value
