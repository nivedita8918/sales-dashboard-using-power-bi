# Data Dictionary

| Column | Meaning | Suggested type |
| --- | --- | --- |
| Row ID | Unique row identifier | Whole number |
| Order ID | Sales order identifier | Text |
| Order Date | Date when the order was placed | Date |
| Ship Date | Date when the order was shipped | Date |
| Ship Mode | Delivery method | Text |
| Customer ID / Customer Name | Customer identifiers | Text |
| Segment | Customer segment | Text |
| Country, City, State, Postal Code, Region | Geographic details | Text / whole number |
| Product ID / Product Name | Product identifiers | Text |
| Category / Sub-Category | Product grouping | Text |
| Sales | Sales revenue | Decimal number / currency |
| Quantity | Units sold | Whole number |
| Discount | Discount applied | Decimal number / percentage |
| Profit | Profit generated | Decimal number / currency |
